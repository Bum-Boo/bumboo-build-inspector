# Dependency and Supply Chain Checklist

Use this checklist during post-build dependency and supply-chain audits.

| Item | Status | Evidence | Required action | Release blocker? |
|---|---|---|---|---|
| Package manifests are identified | Unknown |  |  |  |
| Lockfiles are present | Unknown |  |  |  |
| Versions are pinned or constrained safely | Unknown |  |  |  |
| New dependencies are justified | Unknown |  |  |  |
| Dependencies appear real and maintained | Unknown |  |  |  |
| Suspicious package names checked | Unknown |  |  |  |
| Postinstall/preinstall scripts reviewed | Unknown |  |  |  |
| CI/CD third-party actions are pinned | Unknown |  |  |  |
| Container base images are reviewed | Unknown |  |  |  |
| Remote install scripts avoided or justified | Unknown |  |  |  |
| Dependency vulnerability scan exists | Unknown |  |  |  |
| License risks reviewed | Unknown |  |  |  |
| SBOM/provenance process exists if needed | Unknown |  |  |  |
| Secrets are not exposed in CI/CD | Unknown |  |  |  |
| Build artifacts are reproducible enough for release | Unknown |  |  |  |
