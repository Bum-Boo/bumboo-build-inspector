# AI-Generated Code Checklist

| Item | Status | Evidence | Required action | Release blocker? |
|---|---|---|---|---|
| AI-generated code treated as untrusted | Unknown |  |  |  |
| Critical flows have human-readable requirements | Unknown |  |  |  |
| Tests verify intended behavior, not implementation details | Unknown |  |  |  |
| Negative tests exist | Unknown |  |  |  |
| Security tests exist for sensitive flows | Unknown |  |  |  |
| Authorization checks are explicit | Unknown |  |  |  |
| Input validation is explicit | Unknown |  |  |  |
| Error handling is intentional | Unknown |  |  |  |
| Dependencies are verified and justified | Unknown |  |  |  |
| Hallucinated dependencies checked | Unknown |  |  |  |
| Agent instructions are separated from untrusted content | Unknown |  |  |  |
| AI tool permissions are limited | Unknown |  |  |  |
| Production credentials are not available to agents | Unknown |  |  |  |
| Prompt injection surfaces are identified | Unknown |  |  |  |
| AI outputs are validated before downstream use | Unknown |  |  |  |
| Generated docs do not overstate system guarantees | Unknown |  |  |  |
